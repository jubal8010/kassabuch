# Kassabuch

Offline-Kassabuch als Web-App: Verkauf, Einkauf, Ausgaben, Lager und Rechnungen.
Alle Daten bleiben im Speicher des Geräts – dieses Repository enthält nur die leere App.


## Training-App

Trainings-Tracker unter `training/` – erreichbar unter https://jubal8010.github.io/kassabuch/training/ . Eigenständige App mit eigenem Speicher (`training.v1`) und eigenem Offline-Cache.
